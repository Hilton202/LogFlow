⚙️ Configurações de Notificações

Como obter seu Token:
1. Abra o Telegram e procure por @BotFather
2. Envie o comando /start
3. Envie /newbot e siga as instruções
4. Copie o token gerado (algo como: 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11)
⚠️ Mantenha este token em segurança!
Como obter seu Chat ID:
1. Envie uma mensagem qualquer para o seu bot
2. Acesse: https://api.telegram.org/bot{SEU_TOKEN}/getUpdates
3. Procure por "id" dentro de "from"
4. Copie este número (ex: 123456789)
⚠️ Este ID identifica VOCÊ no Telegram!

ℹ️ Informações Importantes

🔐 Privacidade e Segurança:
• Seus dados de Telegram são salvos de forma criptografada no banco de dados
• Somente VOCÊ tem acesso às suas configurações
• O Token é necessário para enviar notificações (nunca é compartilhado)
• Você pode alterar ou deletar suas configurações a qualquer momento
📱 Múltiplas Contas:
• Se você tem múltiplas contas (pessoal + empresa), configure cada uma separadamente
• Cada usuário recebe notificações apenas de sua própria conta
• Ideal para manter dados separados e bem organizados
